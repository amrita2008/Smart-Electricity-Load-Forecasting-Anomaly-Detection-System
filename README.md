# Smart-Electricity-Load-Forecasting-Anomaly-Detection-System
🎯 Real-Life Problem:
 In hostels, PGs, apartments, labs, offices electricity consumption spikes unexpectedly bills increase without clarity faulty devices / misuse go unnoticed.

✅ This System:
1.Forecast future electricity load (next hour / next day)
2.Detect abnormal usage patterns
3.Explain anomalies
4.Expose predictions via API


## System Architecture
- LSTM model trained on historical electricity load data
- Model deployed using FastAPI
- API hosted on Render
- Streamlit dashboard for real-time prediction and visualization
- Input validation, error handling, and API security implemented
